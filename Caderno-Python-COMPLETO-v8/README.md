# Caderno Python

**[Abrir o site](https://gabrielherzer.github.io/caderno_python/)**

Listas do professor Massanori, prática de Python e revisão para a prova.

- Catálogo com os 33 exercícios das listas 10 a 14 e treinos ENADE.
- Editor Python com verificação automática, dicas após tentativa e solução por pedido.
- Revisão por tema com sintaxe, exemplos e foco nas dificuldades.
- Simulado com oito questões fixas: arroz, alturas, count_code, fixa_primeiro, busca, zf, sort_last e anagrama.
- Reinício do simulado, respostas salvas, histórico de acertos e backup.

No arroz, a função arroz(n) retorna somente uma lista simples com n * n quantidades, na ordem das casas.

O progresso fica salvo no navegador. Internet necessária para executar Python.
